# concurrency-yamling
Выполнение очередного тестового задания

### Запуск

Для сборки выполнить команду 
```shell
make build
```

Для запуска выполнить команду
```shell
./bin/concurrency-yamling
```

Есть возможность передать параметры, посмотреть использование:
```shell
./bin/concurrency-yamling -h
```

Результат работы программы наблюдать в директории **./storage/**.



### Что здесь происходит

Создаются некие задачи, которые сохраняются в директорию **storage-dir** как yaml-файлы.

Задачи обрабатываются в нескольких горутинах.
